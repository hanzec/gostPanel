# yagp 界面设计标准

yagp 的「Midnight Relay」界面面向日常维护 Gost 节点的管理员。UI/UX Pro Max 的设计系统查询选出了高对比深色、状态色、紧凑数据布局和等宽数字。交互标准来自它的可访问性、响应式表格和表单指引。Google Stitch MCP 用同一个设计资产生成页面参考稿，Vue 负责渲染实际数据和执行操作。 [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) · [Stitch 项目](https://stitch.withgoogle.com/projects/1488212784564018110)

## 视觉和布局

| 项目 | 标准 |
| --- | --- |
| 颜色 | 画布 `#0B1019`，面板 `#121B29`，主操作 `#58E6AE`，主文本 `#EDF4FA`。颜色通过 `--ops-*` 语义变量复用。 |
| 对比度 | 面板上的主文本、次要文本和弱化文本分别为 15.58:1、9.05:1 和 6.62:1。普通文本以 4.5:1 为下限。 |
| 字体 | 使用系统中文无衬线字体。移动端正文和输入为 16px，IP、端口、版本、时刻和计数使用等宽或等宽数字。 |
| 结构 | 桌面使用 224px 分组侧栏和 28px 内容边距。900px 及以下改用抽屉导航，窄屏内容边距为 16px。 |
| 内容密度 | 每页提供一个一级标题和清楚的操作区。页面采用统一的间距与 12px 面板圆角。窄屏管理列表按记录折行，字段标签和操作随记录保留。 |

## 交互验收

- 主要操作使用带文字的按钮，图标按钮提供可读名称。Tab 顺序跟随页面阅读顺序，键盘焦点可见，抽屉和弹窗可关闭。移动端主要操作提供 44px 点击高度。
- 筛选器和表单有可见标签。请求加载、成功、失败和空结果分别呈现。加载失败提供重试，修改动作展示提交状态，删除保留确认。
- 状态同时显示文字和颜色。缩减动画偏好生效。长地址、日志内容和配置路径能折行，或在局部区域滚动。
- 在 375px、768px、1024px 和 1440px 检查导航、筛选器、记录操作和弹窗。页面本身保持在视口宽度内。
- 运行总览显示实际状态分布、后端版本、数据库和最近操作。节点和规则显示 API 返回的收发流量，时间和状态以实际接口响应为准。

## 页面重点

| 页面 | 首要任务 |
| --- | --- |
| 运行总览 | 查看节点、规则和隧道的运行状态，再进入待处理的列表。 |
| 节点管理 | 查找实例，查看连接与流量，访问节点配置和安装命令。 |
| 规则管理 | 核对入口、目标和流量，启停转发，导入或导出规则。 |
| 隧道管理 | 对照入口、出口、协议和中继端口，管理隧道状态。 |
| 操作日志 | 按管理员、动作和资源筛选记录，展开查看事件细节。 |
| 系统设置 | 分区编辑面板和 SMTP 配置，按数据库能力提供备份操作。 |
